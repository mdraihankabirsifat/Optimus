# Asset tools

Everything the cave is made of is generated by the two scripts in this folder. Nothing in
`assets/` is hand-authored, downloaded, or licensed from anyone — which means there is
nothing to credit, nothing that can be rejected at submission, and the whole set can be
re-tuned by changing a number and re-running.

Both tools are **idempotent**: they overwrite their own output and touch nothing else.
Run them as often as you like.

---

## 1. Stone textures — `gen_textures.py`

```bash
python3 tools/gen_textures.py        # ~1 second
```

**Needs:** Python 3 with Pillow (already installed).
**Writes:** `assets/textures/stone_{floor,wall,ceiling}_{albedo,normal,rough,ao}.png`

Twelve 512×512 maps synthesised from layered value noise. The normal maps are the
important part — without them every surface in the cave is lit perfectly flat no matter
how much geometry sits behind it, which is what made the first art pass read as
untextured boxes.

**Knobs worth turning** (top of the file, and in `build()` at the bottom):

| What | Where | Effect |
|---|---|---|
| `SIZE` | line ~20 | Resolution. 512 is plenty; 1024 quadruples file size for little gain. |
| `crack_strength` | `build()` calls | How pronounced the cracks are. Wall uses 0.70, floor 0.40. |
| `normal_strength` | `build()` calls | Depth of the relief. Raise for craggier rock; above ~4 it starts to look embossed. |
| `tint` | `build()` calls | Per-surface colour bias. Kept near-white so the material can tint at runtime. |

To add a **new surface type**, add one `build()` line with a fresh seed, then reference
`"stone_<name>"` from `cave_builder.gd`.

## 2. Rock props — `gen_rocks.py`

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --python tools/gen_rocks.py
```

**Needs:** Blender (installed via `brew install --cask blender`).
**Writes:** `assets/models/*.glb` (16 pieces, ~400 KB total) and preview renders into
`tools/preview/` so you can check the result without opening Blender.

Each piece is a primitive plus displacement modifiers, decimated to a poly budget it can
afford when instanced hundreds of times.

| Family | Count | Tris each | Used for |
|---|---|---|---|
| `boulder_XX` | 5 | 80 | Chunks on cave floors |
| `wall_panel_XX` | 4 | ~1050 | Eroded slabs fronting flat wall faces |
| `stalactite_XX` | 3 | 216 | Hanging from ceilings |
| `rubble_XX` | 4 | 80 | Small debris scatter |

### Two rules that will bite you

**Displacement strength must be proportional to the object's own size.** At `0.55` on a
radius-1 sphere the boulders came out as spiky crumpled stars. The stalactite looked fine
at the same nominal number only because it is 2.4 units long. If a shape comes out
shattered, lower the strength before anything else.

**On the wall panels, Solidify runs before Displace.** Thickening an already-displaced
sheet pushes its peaks apart into separated shards that read as broken glass.

### Adding a new prop

1. Write a function that builds it and ends with `return finish(obj, "name_%02d" % index, <face budget>)`.
2. Add it to the `jobs` list in `main()`.
3. Add its name to the preview list at the bottom of `main()` so you get a render.
4. In `cave_builder.gd`, add a `*_VARIANTS` constant and a `_bucket(...)` call in
   `_add_detail()`, then an `_emit_props(...)` line.

Props are placed deterministically from the cave's graph hash and carry **no collision**,
so nothing you add here can block a route or wedge a racer.

## What these tools do not cover

**Characters.** The racers are still capsules. Modelling one in Blender is easy; rigging
and animating it headless is slow and hard to verify. [Kenney's blocky
characters](https://kenney.nl/assets/blocky-characters) are CC0 and already rigged — that
is minutes of work against hours, and CC0 means no attribution risk at submission.

**Audio.** Nothing here makes sound. Kenney's audio packs are CC0; Freesound is fine but
its licences are per-file and must each be checked.

Anything you do download goes in `CREDITS.md` the moment you add it, not at the end.

## Regenerating everything

```bash
python3 tools/gen_textures.py
/Applications/Blender.app/Contents/MacOS/Blender --background --python tools/gen_rocks.py
godot --headless --editor --quit        # re-import the new files
godot                                   # look at it
```
